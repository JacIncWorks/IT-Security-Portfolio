# IT & Cybersecurity Portfolio

Welcome to my IT and Cybersecurity Portfolio!

This repository documents my hands-on technical development as I build practical skills in IT support, networking, Linux administration, Windows troubleshooting, and cybersecurity.

My primary objective is to establish a strong foundation in IT operations and technical support while progressively developing the analytical and technical capabilities needed for a future career in cybersecurity.

Rather than focusing exclusively on theory, this portfolio emphasizes practical investigations, troubleshooting exercises, command-line tools, technical documentation, and evidence-based problem-solving.

---

## Technical Skills & Areas of Development

### IT Support & Troubleshooting
Practical help-desk scenarios focused on diagnosing user issues, identifying root causes, and documenting resolutions.

- Incident triage and prioritization
- Windows troubleshooting and performance analysis
- DNS and DHCP troubleshooting
- IP configuration and network connectivity
- Authentication, authorization, and account management
- User permissions and access control
- Security awareness and incident escalation
- Technical documentation and ticket resolution

### Networking
Developing an understanding of network communication, protocols, and infrastructure.

- TCP/IP fundamentals
- TCP and UDP protocols
- IP addressing and subnetting fundamentals
- DNS and DHCP
- Network ports and services
- Multicast DNS (mDNS)
- Network reconnaissance and service discovery
- Packet inspection and traffic analysis

### Linux Administration
Hands-on practice with Linux environments and command-line administration.

- Command-line navigation
- File and directory management
- File permissions
- Process management
- Service inspection
- Package management and verification
- Basic system administration

### Windows Investigation
Investigating Windows processes, services, and system activity.

- Process identification and management
- PID-to-network correlation
- Application traffic investigation
- Windows system utilities
- Performance monitoring
- Resource utilization analysis
- Event and activity investigation

### Cybersecurity & Security Analysis
Developing practical investigative skills through security-focused exercises.

- Evaluating processes and services
- Identifying potentially suspicious activity
- Correlating technical evidence
- Interpreting network behavior
- Investigating security concerns
- Understanding authentication and access controls
- Documenting findings and investigation limitations
